# 📖 GYAN

**Smart Service Platform**

GYAN is a configurable service platform for print shops, cyber cafés, document centers, schools, libraries, and other local service businesses.

## Vision

Enable customers to:

- Upload documents from home
- Receive notifications when ready
- Collect without waiting
- Access configurable services through a modern tile-based interface

## Technology Stack

- React + TypeScript + Vite
- Spring Boot (planned)
- PostgreSQL (planned)
- Cloudflare
- Google Sheets Configuration (planned)
